1. Oyun nedir?

VirPet, Reigns tarzı bir sanal evcil hayvan oyunudur:

  • Önce pet'inizi oluşturursunuz (şapka, vücut, yüz, bacak).
  • İsmini yazarsınız.
  • Oyun ekranında rastgele olay kartları gelir; Yes veya No seçersiniz.
  • Her seçim dört sayıyı değiştirir: açlık, sevgi, kilo, sağlık (0–100).
  • Zaman geçtikçe değerler kendiliğinden kayar (açlık artar, sevgi azalır…).
  • Sağlık 0 veya sevgi 0 olursa oyun biter; Play again ile başa dönersiniz.

  A[Uygulama açılır] --> B[Oluşturma ekranı]
  B --> C{Start}
  C --> D[Oyun ekranı]
  D --> E[Olay kartı göster]
  E --> F{Yes / No}
  F --> G[Statları güncelle]
  G --> H[Zaman geçişi]
  H --> I{Kaybettin mi?}
  I -->|Hayır| E
  I -->|Evet| J[Game over mesajı]
  J --> K[Play again]
  K --> B

4. Java dosyaları — ne işe yarar?

4.1 StatDelta.java

Bir seçimin dört sayıya etkisini taşır. Kart dosyasında yazılmayan stat 0 kabul edilir.

public final class StatDelta {
    public final int hunger;
    public final int affection;
    public final int weight;
    public final int health;
    public static final StatDelta ZERO = new StatDelta(0, 0, 0, 0);
}

ZERO ne işe yarar?

ZERO, "hiçbir stat'ı değiştirme" anlamına gelen hazır bir sabittir. Kart dosyasında bir kartın yes veya no satırı eksikse, loader her seferinde new StatDelta(0, 0, 0, 0) yaratmak yerine mevcut StatDelta.ZERO nesnesini kullanır. Bunu şöyle düşünün: "boş bir paket" önceden hazır durur — ihtiyaç olduğunda hep aynı kutu kullanılır, gereksiz yere yeni kutu üretmeyiz. Buna sabit nesne (constant object) denir.

Programlama terimi — public static final: public = herkes erişebilir, static = sınıfın kendisine ait (bir kopya, her nesneye değil), final = bir kez atandıktan sonra değiştirilemez. Bu üçlü bir araya gelince ortaya "herkes tarafından kullanılabilen, değişmez sabit" çıkar.

4.2 EventCard.java

Tek kart: kimlik (id), olay metni, Evet/Hayır için iki StatDelta. Getter metotları (getId(), getText() …) alanları dışarı açar ama değiştirmeyi engeller — buna encapsulation (kapsülleme) denir.

4.3 PetGameModel.java

Oyunun "beyni". Stat değişimlerini, zaman geçişini ve kaybetme koşullarını yönetir.

Path nedir?

Java'nın java.nio.file.Path sınıfı, bilgisayardaki bir dosya ya da klasör adresini temsil eder. Bunu "bir yol tarifi kağıdı" gibi düşünün: dosyayı henüz açmaz, sadece nerede olduğunu bilir.

Path partsRoot = Paths.get("assets", "parts");
// → assets/parts

Dosyayı gerçekten okumak için başka metotlar (Files.newInputStream, ImageIO.read) kullanılır. Path tek başına bir adres kartıdır — içindekilere dokunmaz.

enum nedir?

Enum (enumeration = sayım), sınırlı sayıda seçenek tanımlar. Bir değişken bu seçeneklerden yalnızca birini tutabilir — başka bir değer atanamaz. Bunu "tek bir soru için önceden hazırlanmış şıklar" gibi düşünün.

public enum GameOverReason {
    NONE,       // henüz bitmedi
    OBESITY,    // aşırı kiloyuzünden
    STARVATION, // açlıktan
    LEFT_HOME   // sevgi bitince
}

String ("OBESITY") yazmak yerine enum kullanmanın avantajı: yazım hatası yaparsanız derleyici sizi daha kodunuzu çalıştırmadan uyarır. Enum değerleri sabit ve güvenlidir.

private GameOverReason gameOverReason = GameOverReason.NONE;

Bu satır şunu söyler: "Oyun başladığında henüz kaybetme sebebi yok." private kelimesi bu değişkene sadece PetGameModel sınıfının kendi kodunun erişebileceğini bildirir. Oyun bittiğinde bu alan OBESITY, STARVATION veya LEFT_HOME değerlerinden birini alır — o zaman ekranda uygun mesaj gösterilir.

İsim temizleme (üçlü operatör)

String trimmed = petName == null ? "" : petName.trim();
this.petName = trimmed.isEmpty() ? "Pet" : trimmed;

Bu iki satır, kullanıcının yazdığı ismi güvenli hale getirir:

  1. petName == null ? "" : petName.trim() — isim hiç girilmediyse (null) boş metin kullan; girildiyse baştaki ve sondaki boşlukları temizle (trim()). ? : yapısına üçlü (ternary) operatör denir; kısa bir if-else'dir.
  2. Temizlenmiş isim hâlâ boşsa varsayılan olarak "Pet" kullan.

Böylece oyuncu hiçbir şey yazmasa bile model geçerli bir isme sahip olur.

resolveBodyPath — dosya yolu birleştirme

Path base = partsRoot.resolve("bodies").resolve(idStr);
if (weight < WEIGHT_SKINNY) {
    return base.resolve("skinny").resolve("body" + bodyStyleId + "S.png");
}
if (weight > WEIGHT_FAT) {
    return base.resolve("fat").resolve("body" + bodyStyleId + "F.png");
}
return base.resolve("normal").resolve("body" + bodyStyleId + ".png");

Burada iki önemli kavram var:

  • base — temel yol. Kök klasörden (assets/parts) başlayıp bodies/1 gibi bir klasöre kadar inen adres. Bir nevi "şehir" adresi.
  • resolve — bu adresin sonuna bir alt klasör veya dosya adı ekler. base.resolve("skinny") → assets/parts/bodies/1/skinny. Bunu "adrese sokak numarası eklemek" gibi düşünün.

Bu fonksiyon, pet'in kilosuna göre hangi vücut resminin gösterileceğini belirler. Zayıfsa skinny, şişmansa fat, normaldeyse normal klasöründen dosya yolunu döndürür.

Önemli sabitler:

  • WEIGHT_SKINNY = 35, WEIGHT_FAT = 65 — hangi vücut resmi?
  • AFFECTION_SAD / HAPPY — hangi yüz resmi?
  • Her tur: açlık +3, kilo −2, sevgi −1; aşırı kiloda sağlık −2
public void applyChoice(StatDelta delta) {
    hunger = clamp(hunger + delta.hunger);
    // ... diğer statlar
    applyTimePassage();
}

clamp değeri 0–100 arasında tutar — taşma olmaz.

4.4 PetSpriteComposer.java

Sprite (oyundaki küçük karakter resmi) oluşturmaktan sorumludur. Ayrı ayrı çizilmiş bacak, gövde, yüz ve şapka parçalarını üst üste koyarak tek bir görüntü üretir.

BufferedImage nedir?

Java'nın java.awt.image.BufferedImage sınıfı, bellekteki bir resmi temsil eder. Bunu dijital bir tuval (canvas) gibi düşünün: piksel piksel renk bilgisi içerir. PNG dosyasını ImageIO.read ile okuduğunuzda elde ettiğiniz şey bir BufferedImage'dir.

BufferedImage out = new BufferedImage(16, 48, BufferedImage.TYPE_INT_ARGB);

Bu satır 16 piksel genişliğinde, 48 piksel yüksekliğinde boş bir tuval oluşturur. TYPE_INT_ARGB her pikselin alfa (saydamlık), kırmızı, yeşil, mavi kanalı olduğunu belirtir.

Graphics2D nedir ve grafik nasıl çizilir?

Graphics2D, Java'nın çizim kalemini temsil eder. Bir BufferedImage üzerine şekil çizmek, metin yazmak veya başka bir resmi yapıştırmak istediğinizde bu nesneyi kullanırsınız.

Graphics2D g = out.createGraphics();  // tuvalden kalem al
drawAt(g, leg, 0, 32);               // bacakları y=32'ye çiz
drawAt(g, body, 0, 16);              // gövdeyi y=16'ya çiz
drawAt(g, face, 0, 16);              // yüzü y=16'ya çiz
drawAt(g, hat, 0, 0);                // şapkayı en üste çiz
g.dispose();                          // kalemi bırak

Her drawAt çağrısı, ilgili PNG dosyasını okuyup belirtilen koordinata yapıştırır. Parçalar alttan üste sırayla çizildiğinden üstteki katman alttakini kaplar — tıpkı kağıtları üst üste koymak gibi.

Sonunda elde edilen BufferedImage ekrandaki panele g2.drawImage ile çizilir ve kullanıcı birleşik sprite'ı görür. dispose() çağrısı kalemi serbest bırakır — kullanılmayan kaynakları temizlemek iyi bir alışkanlıktır.

4.5 EventCardLoader.java

event_cards.cards dosyasını satır satır okuyup kart listesi üretir. Her kart şu formattadır:

card empty_bowl
text
The food bowl is empty...
yes hunger=-14 affection=3 weight=6
no hunger=6 affection=-6
end

# ile başlayan satırlar ve boş satırlar yok sayılır.

public static List<EventCard> load(Path path) throws IOException ne demek?

Bu satır bir metot tanımıdır. Her kelimeyi tek tek açıklayalım:

  • public — Herkes bu metodu çağırabilir (dışarıya açık).
  • static — Metot sınıfın kendisine aittir; bir EventCardLoader nesnesi oluşturmadan EventCardLoader.load(...) şeklinde çağrılabilir.
  • List<EventCard> — Metodun döndürdüğü şey: EventCard nesnelerinden oluşan bir liste. Metot çağrıldığında geriye 44 kartlık bir liste verir.
  • load — Metodun adı.
  • Path path — Metodun aldığı parametre: okunacak dosyanın yolu. Çağırırken EventCardLoader.load(ASSETS.resolve("event_cards.cards")) dersiniz — bu path parametresine dosya adresini verir.
  • throws IOException — "Bu metot dosya okuma hatası fırlatabilir" uyarısı. Çağıran taraf bu hatayı try-catch ile yakalamalı ya da kendi de throws ile bildirmelidir.

while döngüsü nasıl çalışıyor?

while ((line = reader.readLine()) != null) {
    String t = line.trim();
    if (t.isEmpty() || t.startsWith("#")) continue;

    if (t.startsWith("card "))       → yeni kart başlat
    else if ("text".equals(t))       → metin toplama moduna geç
    else if ("end".equals(t))        → kartı listeye ekle
    else if (t.startsWith("yes"))    → yes deltasını oku
    else if (t.startsWith("no"))     → no deltasını oku
    else if (inText)                 → metin satırını ekle
}

Adım adım:

  1. reader.readLine() — Dosyadan bir satır okur. Dosya bitince null döner ve döngü sona erer.
  2. line = reader.readLine() — Okunan satırı line değişkenine atar. Parantez içindeki = sayesinde hem atama yapılır hem de dönen değer != null ile kontrol edilir — tek satırda iki iş birden.
  3. Her döngü turunda satır trimlenip (boşlukları temizlenip) hangi anahtar kelimeyle başladığına bakılır.
  4. card → yeni kart için değişkenler sıfırlanır. text → bundan sonraki satırlar metin olarak toplanır. yes/no → delta parse edilir. end → toplanan verilerle bir EventCard oluşturulur ve listeye eklenir.
  5. inText bayrak değişkeni: text satırı okunduğunda true olur, yes/no/end satırı okunduğunda false olur. Bu bayrak aktifken gelen satırlar olay metnine eklenir.
try (BufferedReader reader = ...) yapısına try-with-resources denir. Dosya okuyucu try bloğu bitince otomatik kapatılır — reader.close() yazmaya gerek kalmaz. Açtığınız dosyayı kapatmazsanız işletim sistemi kaynakları boşa harcanır; bu yapı onu önler.

StringBuilder nedir?

Java'da String (metin) nesneleri değiştirilemezdir — bir metne her ekleme yaptığınızda aslında yeni bir metin oluşur. Az sayıda ekleme için sorun olmaz, ama kart metnini satır satır birleştirirken çok fazla gereksiz kopya üretilir.

StringBuilder, değiştirilebilen bir metin kutusudur. İçine .append() ile parça parça ekleme yaparsınız — kutu büyür ama her seferinde yeni bir kutu oluşmaz. En sonunda .toString() ile bitmiş metni alırsınız.

StringBuilder text = new StringBuilder();
// "text" satırı okunduğunda yeni kutu oluşur

// sonraki her satır kutuya eklenir:
text.append('\n');    // yeni satır karakteri
text.append(line);    // satırın kendisi

// "end" satırına gelince bitmiş metni al:
String sonuc = text.toString();

Böylece olay metni satır satır birleştirilip EventCard nesnesine verilir.

parseDelta ne işe yarar?

yes veya no satırını okuyup StatDelta nesnesine çevirir. Örnek satır:

yes hunger=-14 affection=3 weight=6

Fonksiyon şunları yapar:

  1. "yes" önekinden sonraki kısmı (hunger=-14 affection=3 weight=6) alır.
  2. Boşluklardan parçalara ayırır: ["hunger=-14", "affection=3", "weight=6"].
  3. Her parçayı = işaretinden ikiye böler: isim (hunger) ve değer (-14).
  4. İsme göre doğru değişkene atar (switch ile).
  5. Yazılmayan statlar 0 kalır (ör. health yukarıda yok → 0).
private static StatDelta parseDelta(String rest) {
    int hunger = 0, affection = 0, weight = 0, health = 0;
    for (String token : rest.split("\\s+")) {
        int eq = token.indexOf('=');
        int v = Integer.parseInt(token.substring(eq + 1));
        switch (token.substring(0, eq)) {
            case "hunger": hunger = v; break;
            // ...
        }
    }
    return new StatDelta(hunger, affection, weight, health);
}

4.6 EventCardDeck.java

Kartları rastgele çeker; mümkünse üst üste aynı kartı vermez.

List nedir?

List, Java'da sıralı bir eleman koleksiyonudur — tıpkı bir alışveriş listesi gibi. Her elemanın bir sırası (indeksi) vardır ve istediğiniz zaman sıradaki elemana .get(indeks) ile ulaşabilirsiniz.

List<EventCard> cards = new ArrayList<>();
cards.add(birKart);      // listeye ekle
cards.get(0);            // ilk elemanı al
cards.size();            // listede kaç eleman var

<EventCard> kısmı "bu listenin elemanları EventCard tipindedir" demektir. Buna generic (tür parametresi) denir — listeye yanlışlıkla başka türde nesne koymanızı önler.

Yapıcı fonksiyon ve Collections.unmodifiableList

public EventCardDeck(List<EventCard> cards) {
    if (cards == null || cards.isEmpty()) {
        throw new IllegalArgumentException("cards must not be empty");
    }
    this.cards = Collections.unmodifiableList(new ArrayList<>(cards));
}

Bu satır sağdan sola doğru okunursa daha iyi anlaşılır:

  1. new ArrayList<>(cards) — Gelen listenin bir kopyasını oluşturur. Neden kopya? Çünkü dışarıdan gelen cards listesine birisi sonradan eleman ekleyip çıkarabilir; kendi kopyamızı yaparsak dış değişikliklerden etkilenmeyiz. Bunu "birisinin alışveriş listesini fotokopi çekmek" gibi düşünün — artık orijinal listeye ne yapılırsa yapılsın, sizin kopyanız güvende.
  2. Collections.unmodifiableList(...) — Bu kopyayı sadece okunabilir hale getirir. Artık bu listeye .add(), .remove() veya .set() çağrılırsa program hata fırlatır. Amaç: kart destesi bir kez oluşturulduktan sonra içeriği değişmesin — yanlışlıkla kart eklenip silinmesin.
  3. this.cards = ... — Sonucu nesnenin kendi cards alanına atar. this "şu anki nesne" demektir; bu satırda parametre ile alan aynı isme sahip olduğu için this ile ayrım yapılır.
Özet: Collections.unmodifiableList(new ArrayList<>(cards)) = "gelen listenin değiştirilemez bir kopyasını yap". Savunmacı bir programlama tekniğidir — verinin yanlışlıkla bozulmasını önler.

EventCardDeck nasıl çalışır? — Genel bakış

Bu sınıf çok basit bir iş yapar: elindeki kart listesinden rastgele kart çekmek. Yapıcı fonksiyon kartları alır ve güvenli bir kopyasını saklar. Sonra drawNext() çağrıldığında rastgele bir kart seçer — ama son çekilen kartın aynısını vermemeye çalışır (do-while döngüsü). Tek alan: lastDrawn = "en son çekilen kart".

drawNext nasıl çalışır?

public EventCard drawNext() {
    if (cards.size() == 1) {
        lastDrawn = cards.get(0);
        return lastDrawn;
    }
    EventCard next;
    do {
        next = cards.get(random.nextInt(cards.size()));
    } while (next == lastDrawn);
    lastDrawn = next;
    return next;
}

Adım adım:

  1. Tek kart varsa onu döndürür (başka seçenek yok).
  2. Birden fazla kart varsa: rastgele bir kart seç.
  3. Seçilen kart bir öncekiyle aynıysa (next == lastDrawn), tekrar seç.
  4. Bu do-while döngüsü farklı bir kart bulunana kadar devam eder.
  5. Bulunan kartı lastDrawn olarak kaydet ve döndür.

Bu basit "tekrar önleme" yöntemi, oyuncunun art arda aynı soruyu görmesini engeller. 44 kart olduğunda döngü genellikle 1–2 denemede farklı bir kart bulur.

4.7 PetCreationApp.java

Projenin en büyük dosyası. İki ekran arasında geçiş yapar (CardLayout): creation (oluşturma) ve game (oyun). Aşağıda bu dosyadaki temel kavramları tek tek açıklıyoruz.

loadGameFont — fontu yükleme

private static Font loadGameFont() throws IOException, FontFormatException {
    Path fontPath = findFirstFontInAssets();
    if (fontPath == null || !Files.isRegularFile(fontPath)) {
        return new Font(Font.SANS_SERIF, Font.PLAIN, Math.round(FONT_UI));
    }
    try (InputStream in = Files.newInputStream(fontPath)) {
        Font base = Font.createFont(Font.TRUETYPE_FONT, in);
        GraphicsEnvironment.getLocalGraphicsEnvironment().registerFont(base);
        return base;
    }
}

Bu fonksiyon oyunun yazı tipini yükler. Adım adım:

  1. findFirstFontInAssets() — assets/ içindeki ilk .ttf veya .otf dosyasını arar. Bulursa dosya yolunu döndürür.
  2. Font dosyası bulunamazsa veya geçerli bir dosya değilse, sistemin varsayılan fontu (Font.SANS_SERIF) kullanılır — program çökmeden devam eder.
  3. Font dosyası varsa: Files.newInputStream ile dosyanın bayt akışını açar, Font.createFont ile bu akıştan bir Font nesnesi oluşturur.
  4. registerFont — oluşturulan fontu Java'nın grafik ortamına kaydeder; böylece tüm bileşenler bu fontu kullanabilir.
  5. try (...) yapısı sayesinde InputStream otomatik kapatılır.
throws IOException, FontFormatException — Bu metot iki tür hata fırlatabilir: dosya okuma hatası (IOException) ve geçersiz font formatı hatası (FontFormatException). Çağıran taraf bunları yakalamalıdır.

DirectoryStream — klasör içeriğini gezme

try (DirectoryStream<Path> stream = Files.newDirectoryStream(ASSETS, pattern)) {
    for (Path p : stream) {
        return p;
    }
}

DirectoryStream, bir klasörün içindeki dosyaları tek tek gezen bir yapıdır. Bunu "bir klasörü açıp içindeki dosyaları sırayla kontrol etmek" gibi düşünün.

  • Files.newDirectoryStream(ASSETS, pattern) — ASSETS klasörünü açar ve sadece pattern'e uyan dosyaları gezer. Örneğin "*.ttf" pattern'i yalnızca .ttf uzantılı dosyaları gösterir.
  • for (Path p : stream) — Bulunan her dosya yolunu p değişkenine atar ve döngü gövdesini çalıştırır.
  • try (...) ile sarmalanması gerekir çünkü DirectoryStream bir işletim sistemi kaynağıdır — işi bitince kapatılmalıdır.

Kısacası: DirectoryStream = "şu klasördeki dosyaları filtreli olarak listele".

findFirstFontInAssets — ilk font dosyasını bul

private static Path findFirstFontInAssets() throws IOException {
    String[] patterns = {"*.ttf", "*.TTF", "*.otf", "*.OTF"};
    for (String pattern : patterns) {
        try (DirectoryStream<Path> stream = Files.newDirectoryStream(ASSETS, pattern)) {
            for (Path p : stream) {
                return p;
            }
        }
    }
    return null;
}

Bu fonksiyon assets/ klasöründeki ilk font dosyasını bulmaya çalışır:

  1. Dört farklı pattern dener: *.ttf, *.TTF, *.otf, *.OTF. Farklı büyük/küçük harf kombinasyonlarını denemesinin sebebi: bazı dosya sistemlerinde büyük-küçük harf ayrımı vardır (Linux gibi). DS-TERM.TTF dosyası *.ttf pattern'ine uymaz ama *.TTF'e uyar.
  2. Her pattern için DirectoryStream ile klasörü tarar.
  3. İlk eşleşen dosyayı hemen döndürür — geri kalanına bakmaz (return p). Çünkü tek bir font yeterlidir.
  4. Hiçbir pattern eşleşme vermezse null döner. loadGameFont bu durumda varsayılan fontu kullanır.

Bu yaklaşım sayesinde font dosyasının adını kodda sabit yazmaya gerek kalmaz — klasöre hangi fontu koyarsanız onu otomatik bulur.

applyGlobalFonts — global fontlar

Bunu CSS'teki body { font-family: ... } kuralına benzetebilirsiniz — bir kez yazarsınız, her yere uygulanır. "Global font" denmesinin sebebi budur: tek tek değil, toptan ayarlanır.

JTextPane nedir?

JTextPane, Swing'de zengin metin gösterebilen bir bileşendir. Normal JLabel sadece düz metin gösterir; JTextPane ise HTML biçimlendirmesi destekler — kalın yazı, renkli metin, farklı boyutlar gibi.

BorderFactory nedir?

BorderFactory, bileşenlerin etrafına çeşitli çerçeveler üreten fabrika sınıfıdır. "Bana şu tarzda bir kenarlık ver" dersiniz, o da size hazır bir nesne döndürür. Projede kullandığımız dört tür kenarlık:

1. createLineBorder(renk, kalınlık, yuvarlatılmış) — İnce çizgi kenarlık.

BorderFactory.createLineBorder(COZY_BORDER, 1, true)

Bileşenin etrafına 1 piksel kalınlığında, belirtilen renkte bir çizgi çizer. Üçüncü parametre true ise köşeler yuvarlatılır. CSS'teki border: 1px solid renk; border-radius: ...'a karşılık gelir.

2. createEmptyBorder(üst, sol, alt, sağ) — İç boşluk kenarlığı.

BorderFactory.createEmptyBorder(10, 12, 10, 12)

Görünür bir çizgi çizmez; sadece bileşenin içeriği ile kenarı arasına boşluk koyar. CSS'teki padding: 10px 12px'e karşılık gelir. Yazının kenara yapışmaması için kullanılır.

3. createCompoundBorder(dışKenarlık, içKenarlık) — İkisini birleştirir.

BorderFactory.createCompoundBorder(
    BorderFactory.createLineBorder(renk, 1, true),  // dış: çizgi
    BorderFactory.createEmptyBorder(10, 12, 10, 12) // iç: boşluk
)

Dışta görünür bir çerçeve, içte boşluk — ikisi tek bir kenarlık nesnesi olarak atanır. CSS'te border + padding birlikte kullanmaya benzer.

4. createTitledBorder(kenarlık, başlık) — Başlıklı kenarlık.

BorderFactory.createTitledBorder(
    BorderFactory.createLineBorder(renk, 1, true), "Event")

Çerçevenin üst kenarında küçük bir etiket ("Event") görüntüler. Gruplandırma amaçlıdır — HTML'deki <fieldset><legend> yapısına benzer.

Tüm bu kenarlıklar setBorder() ile bileşene atanır.

private static void styleCozyButton(javax.swing.AbstractButton b) {

scanNumberedPng — numaralı PNG dosyalarını tarama

private static List<Path> scanNumberedPng(Path dir, String prefix) throws IOException {
    if (!Files.isDirectory(dir)) {
        return Collections.emptyList();
    }
    Pattern pattern = Pattern.compile(
        "^" + Pattern.quote(prefix) + "(\\d+)\\.png$",
        Pattern.CASE_INSENSITIVE);
    List<Integer> ids = new ArrayList<>();
    try (DirectoryStream<Path> stream = Files.newDirectoryStream(dir, "*.png")) {
        for (Path p : stream) {
            String name = p.getFileName().toString();
            Matcher m = pattern.matcher(name);
            if (m.matches()) {
                ids.add(Integer.parseInt(m.group(1)));
            }
        }
    }
    Collections.sort(ids);
    List<Path> out = new ArrayList<>();
    for (int id : ids) {
        out.add(dir.resolve(prefix + id + ".png"));
    }
    return out;
}

Bu fonksiyon, bir klasördeki hat0.png, hat1.png, hat2.png gibi numaralı dosyaları bulur ve sıralı bir liste olarak döndürür. Adım adım:

  1. Verilen klasör yoksa boş liste döner.
  2. Bir regex (düzenli ifade) kalıbı oluşturur: ^hat(\d+)\.png$ gibi. Bu kalıp "hat ile başla, ardından bir veya daha fazla rakam gelsin, .png ile bitsin" demektir.
  3. DirectoryStream ile klasördeki tüm *.png dosyalarını gezer.
  4. Her dosya adını regex'e karşı kontrol eder. Eşleşirse parantez içindeki rakamı (grup 1) alır ve ids listesine ekler.
  5. Numaraları sıralar (Collections.sort), sonra her numara için tam dosya yolunu (dir.resolve("hat0.png")) oluşturup listeye ekler.

Böylece oyun başlarken kaç şapka/bacak parçası var otomatik tespit edilir — yeni parça eklemek için dosyayı klasöre koymak yeterlidir, kodda değişiklik gerekmez.

!name.matches("\\d+") — regex ile sayı kontrolü

String name = child.getFileName().toString();
if (!name.matches("\\d+")) {
    continue;
}

Bu satır, bir klasör adının sadece rakamlardan oluşup oluşmadığını kontrol eder.

  • \\d — Regex'te "herhangi bir rakam" (0–9) demektir. Java'da ters eğik çizgi (\) kaçış karakteri olduğundan \\d yazılır.
  • + — "Bir veya daha fazla" demektir. \\d+ = "bir veya daha fazla rakam".
  • matches — Metnin tamamının bu kalıba uyup uymadığını kontrol eder.
  • ! — Sonucu tersine çevirir (değilse).

Yani satır şunu söyler: "Klasör adı sadece rakamlardan oluşmuyorsa bu klasörü atla." bodies/ altındaki alt klasörler 1, 2, 3 gibi numaralıdır; .DS_Store gibi istenmeyen dosya/klasörler bu kontrolle elenir.

Yazıları panele sığdırma (wrapTextToLines)

Olay kartı metni panelden geniş olabilir. Metni satırlara bölme işlemi şöyle çalışır:

  1. Metin boşluklardan kelimelere ayrılır.
  2. Her kelime mevcut satıra eklenir. Eklenen kelimeyle birlikte satır panelden taşıyorsa, kelime yeni satıra geçer.

6. Temel algoritmalar (başlangıç seviyesi)

6.1 clamp — sınırlama

Değeri minimum ve maksimum arasında tutar.

private static int clamp(int v) {
    if (v < 0) return 0;
    if (v > 100) return 100;
    return v;
}

6.2 floorMod — döngüsel indeks

Şapka listesinde 3. öğeden sonra 1. öğeye dönmek için:

hatIndex = floorMod(hatIndex + delta, hatPaths.size());

Negatif delta ile geri gidebilirsiniz; Java'nın % operatörü negatifte farklı davranabilir, bu yüzden özel bir yardımcı kullanılır.

  1. Metni boşluklardan kelimelere böl.
  2. Her kelimeyi satıra ekle; sığmazsa yeni satır.
  3. Çok uzun kelime varsa harf harf böl.

9. Android port (detaylı)

androidPort/ klasörü, aynı oyun mantığını telefona taşır. Ama telefon ortamı masaüstünden çok farklıdır — aşağıda ne değişti ve neden değişti açıklanıyor.

9.1 Yapısal fark: tek dosya

Masaüstünde 8 ayrı Java dosyası var. Android'de bunların hepsi VirPetActivity.java içindeki iç sınıflar (nested/inner class) olarak yaşar. Neden? Android projesi Gradle ile derlenir ve paket yapısı farklıdır; tüm mantığı tek dosyada tutmak bağımlılık yönetimini basitleştirir.

9.2 Dosya okuma: Path yerine AssetManager

Masaüstünde dosyalar java.nio.file.Path ve Files ile okunur (işletim sistemi dosya yolları). Android'de APK içindeki dosyalara doğrudan dosya yoluyla erişemezsiniz — bunun yerine AssetManager kullanılır:

// Masaüstü
BufferedImage img = ImageIO.read(path.toFile());

// Android
InputStream in = assets.open("parts/bodies/1/normal/body1.png");
Bitmap img = BitmapFactory.decodeStream(in);

Bu yüzden Android'de dosya yolları Path yerine String olarak tutulur.

9.5 Ses: ProcessBuilder yerine MediaPlayer

Masaüstünde Java kendi başına MP3 çalamaz; harici program (mpv) başlatılır. Android'in MediaPlayer sınıfı MP3'ü doğrudan çalar — harici programa gerek yoktur.

// Masaüstü
ProcessBuilder pb = new ProcessBuilder("mpv", "--really-quiet", file.toString());
bgProcess = pb.start();

// Android
MediaPlayer player = new MediaPlayer();
AssetFileDescriptor afd = am.openFd("bg.mp3");
player.setDataSource(afd.getFileDescriptor(), afd.getStartOffset(), afd.getLength());
player.setLooping(true);
player.prepare();
player.start();

9.6 Font yükleme

Her iki platformda da assets/ kökündeki ilk .ttf / .otf dosyası otomatik bulunur. Masaüstünde Font.createFont, Android'de Typeface.createFromAsset kullanılır. Font bulunamazsa masaüstünde Font.SANS_SERIF, Android'de Typeface.DEFAULT kullanılır.

9.7 Boyut birimleri: piksel yerine dp

Masaüstünde piksel (px) kullanılır; Android'de dp (density-independent pixel) kullanılır. dp, farklı ekran yoğunluklarında aynı fiziksel boyutu korur. dp(8) yardımcı metodu, dp'yi ekrana uygun piksele çevirir.

10. Nasıl çalıştırılır?

Masaüstü

cd virPet
javac -source 8 -target 8 *.java
java PetCreationApp

Proje kökünden çalıştırın; assets/ klasöründe bg.wav, tap.wav, death.wav, runaway.wav olmalı. Ses için ek program gerekmez.

Android

cd androidPort
export ANDROID_HOME=~/Android/Sdk
unset ANDROID_SDK_ROOT
./gradlew assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk
